# Code Metal Forge app screenshots

RIDGELINE and related applications and prototypes from Team 8 at Code Metal Forge Hackathon 2026. No unrelated projects are included.

[Back to the project README](../README.md)

The captions distinguish recorded app UI, controlled demonstrations and early mockups. A screenshot documents a display state, not independent evidence of field accuracy.

## Phone and map synchronization

Development browser captures from November 8, 2026. These show the actual application UI with keyboard test input and a simulated height band, not a physical phone trial or measured outdoor accuracy. The first two captures are from the earlier synchronization build at 7e6acc5. UI details may differ from the current build.

### Desktop terrain map and mirrored phone

Both views show a 1.42 km route and a modelled 95% radius of 269 m after changing the destination on the map.

![Desktop terrain map and mirrored phone](screenshots/desktop-synced.png)

The corresponding phone UI from the same keyboard-driven synchronization check.

![Shared phone interface](screenshots/phone-shared.png)

### Follow guidance

Development capture showing 35 m to the next waypoint, 3.48 km to Rendezvous and a modelled 95% radius of 263 m. Keyboard input and simulated height are visible in the image.
